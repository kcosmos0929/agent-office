# Synthetic Office

내 맥에서 도는 작은 서버가 Claude Code 세션들의 작업 신호를 모아, 보조 모니터엔 **3D 블록 오피스**로, 작은 창·폰·태블릿엔 **목록형 상황판**으로 실시간 보여준다.

- 설계서: `docs/specs/2026-10-22-synthetic-office-설계.md`
- 1단계 계획: `docs/plans/2026-10-22-1단계-구현계획.md`

## 글꼴
오피스 화면의 픽셀 글꼴은 [갈무리(Galmuri)](https://github.com/quiple/galmuri) — SIL Open Font License 1.1 (`web/src/fonts/OFL.txt`).

## 설정
`~/.synthetic-office/config.json`에서 바꾼다(없는 키는 기본값).

| 키 | 기본 | 뜻 |
|---|---|---|
| `restMinutes` | 10 | 차례가 끝난(✅) 뒤 이만큼 지나면 😴 쉬는 중 |
| `leaveMinutes` | 120 | 차례가 끝난 뒤 이만큼 지나면 👋 자동 퇴근, 그 10분 뒤(`goneMinutes`) 화면에서 숨김(지우지 않아 다시 일하면 돌아옴). `restMinutes`보다 작게 적어도 `restMinutes`로 올려 쓴다 |

예전 `idleMinutes`는 더 읽지 않는다.

## 오피스 화면 동작
- **Codex**: Codex 세션도 개발실에 나타난다(책상 0~2번, 자리가 없거나 쉬면 로비). 일하는 책상 옆 서버랙 불빛이 짝으로 깜빡이고 실행 중이면 빨라진다.
- **쉬는 중(😴)**: 휴게실·탕비실로 걸어가 자리를 몇 분마다 바꿔 가며 쉰다. 자리가 차면 넘침 자리에 서고, 그것도 차면 휴게실 앞줄·탕비실에 선다.
- **❗ 승인 · ❓ 질문**: 손 흔드는 그림이 오기 전까지는 앞을 보고 폴짝 뛴다. 오래 숨어 있던 탭이 돌아오면 밀린 걸음을 걷지 않고 지금 자리에 바로 선다.
- **동작 줄이기**: OS의 '동작 줄이기'가 켜져 있으면 폴짝과 링 퍼짐을 끄고(링은 흐려지기만), 반짝은 짧게 보인다.
- **낮밤 미리 보기**: 주소에 `?clock=HH:MM`(예: `/?view=office&clock=21:30`)을 붙이면 그 시각의 서울 하늘·조명으로 본다.
- **앉기**: 여덟 모습 모두 자기 자리 의자에 앉는다 — 사무실 책상(Claude 0~7), 개발실 책상(Codex 0~2), 회의실 의자(도우미 1~6번째, 손 멈춤). 실행·고침은 타이핑, 읽기·생각류는 손 멈춤(상체·깜빡임만), 끝남(✅)은 손을 무릎에 내리고 쉬기(깜빡임만), 나머지 상태(승인·질문·멈춤 등)는 서 있다. 주소에 `?seated=off`(예: `/?view=office&seated=off`)를 붙이면 늘 서 있는 예전 화면, `?seated=still`이면 움직이지 않는 정지 자세.

## 새 버전 반영
서버를 새 화면 빌드(`npm run build:web`)로 다시 켜면, 열려 있던 대시보드 탭이 한 번 저절로 새로 고침된다. 이때 Chrome '항상 위 작은 창'(PiP)은 페이지가 다시 불러와지며 닫히니 다시 열면 된다. 켜 둔 소리와 오피스/목록 선택은 되살리지만, 새로 고친 뒤 브라우저가 소리를 막으면 🔔를 한 번 다시 눌러야 한다.
