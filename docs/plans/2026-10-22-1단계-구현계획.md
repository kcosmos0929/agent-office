# Synthetic Office 1단계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code 세션들의 상태를 내 맥 서버가 모아, 보조 모니터엔 3D 블록 오피스로, 작은 창·폰·태블릿엔 목록형 상황판으로 실시간 보여준다(사용량 TV 포함).

**Architecture:** Claude 훅·상태줄 스크립트가 로컬 서버(:4310)로 신호를 POST → 수집기가 공통 이벤트로 변환 → 상태 정리기(순수 로직, 타이머)가 에이전트 상태를 갱신 → WebSocket으로 전체 스냅샷을 화면에 전송. 화면은 하나의 웹앱이 폭에 따라 3D 오피스(three.js)와 목록형을 고른다. launchd가 로그인 시 서버를 켠다.

**Tech Stack:** Node.js 26(타입 제거로 `.ts` 직접 실행) · TypeScript(타입 검사만) · `ws` · `three` · `qrcode` · Vite · `node:test`

**Spec:** `AI-Sessions/workspace/projects/synthetic-office/2026-10-22-synthetic-office-설계.md` (Task 2에서 레포 `docs/specs/`로 복사)

## Global Constraints

- 레포: `~/developer/synthetic-office/`, GitHub `kcosmos0929/synthetic-office`(비공개). 저장소 생성은 **실행 직전 사용자 확인**.
- Node ≥ 22.18(이 맥 v26.3.0). TS는 **지울 수 있는 문법만**(enum·namespace·생성자 매개변수 속성 금지), import에 `.ts` 확장자, tsconfig `noEmit`·`allowImportingTsExtensions`·`erasableSyntaxOnly`·`strict`.
- 의존성은 `ws`, `three`, `qrcode`만(+ dev: `typescript`, `vite`, `@types/node`, `@types/ws`, `@types/three`, `@types/qrcode`).
- 포트 **4310**. 데이터 폴더 **`~/.synthetic-office/`**(테스트에선 환경변수 `SO_HOME`으로 바꿈). 서버는 시작 시 `endpoint.json` `{port, token, pid}`(권한 0600)을 쓰고 종료 시 지운다. 토큰 파일 `token`(0600).
- **보기 전용**: 화면에서 에이전트에 승인·명령을 보내는 기능 없음.
- **대화 내용 저장·전송 금지**: `prompt`, `last_assistant_message`, `tool_response`, `error` 본문은 수집기에서 버린다. `detail`은 최대 **60자**(코드포인트 기준, 넘으면 `…`), 줄바꿈·제어문자 제거.
- 훅 스크립트: **표준 출력에 아무것도 안 씀, 항상 exit 0**, POST 제한 1000ms, `endpoint.json` 없으면 즉시 종료. settings.json 등록 시 `"timeout": 5`.
- 접속: 루프백(127.0.0.1, ::1, ::ffff:127.0.0.1)의 GET은 토큰 없이 허용. 그 외 GET은 토큰 필요(`?token=` → 쿠키 `so_token` HttpOnly·SameSite=Strict 설정 후 토큰 없는 주소로 302). **모든 POST `/api/*`는 Bearer 토큰 필수**. 비교는 `crypto.timingSafeEqual`. 로그에 토큰 금지. 서버는 `0.0.0.0`에 바인드(폰 접속).
- 시간 기본값: 쉬는 중 **30분**(`done` 지속), 퇴근 목록 제거 **10분**, 응답 없음 **15분**(`thinking`만).
- 색: Claude `#D97757`, Codex `#2F8F83`, ARIA `#8B6CC9`, 대기 강조 `#F5A524`. 모자 팔레트(인덱스 0~7): `#2F4B7C #C04A6B #3E7C4A #6B4E9B #B5651D #2C7A8C #8C2C3C #5C5C5C`.
- 상태 문구(정확히): permission `❗ 승인 필요` · done `✅ 끝남 · 내 차례` · thinking `💭 생각 중` · reading `📖 읽는 중` · editing `✏️ 고치는 중` · running `▶ 실행 중` · delegating `👥 도우미 투입` · stalled `… 응답 없음` · idle `😴 쉬는 중` · gone `👋 퇴근`.
- 목록 정렬: permission → done → (thinking·reading·editing·running·delegating) → stalled → idle → gone, 같은 묶음 안에서는 `since` 오래된 순.
- 화면 선택: `innerWidth ≥ 900 && innerHeight ≥ 600`이면 오피스, 아니면 목록(`?view=list|office`로 강제).
- 위키·OpenClaw는 **읽기만**. settings.json 수정 전 `~/.claude/백업/settings-synthetic-office-설치전-YYYY-MM-DD.json`로 백업.
- 화면 글자는 모두 `textContent`로 넣는다(`innerHTML`에 데이터 금지).
- 알려진 한계: 승인 순간을 알려주는 훅이 없어서, 승인 후 오래 걸리는 도구는 끝날 때까지 `permission`으로 남는다(Task 1에서 대안 신호 확인).

- `prompt` → thinking, 열린 도구 비움. `tool-start` → activity·detail, 열린 도구에 추가(단 현재 permission이면 permission 유지). `tool-end` → 열린 도구에서 빼고, 비면 thinking(현재가 done·idle·gone이면 무시). `permission` → permission·detail. `stop` → done, 열린 도구 비움. `subagent-start/stop` → 목록 추가·제거. `session-end` → gone, 하위 에이전트 비움. `title` → 제목.

- `since`는 **묶음(groupOf)이 바뀔 때만** 갱신. `lastEventAt`은 매 이벤트.
- `tick`: done이 `idleMs` 지나면 idle(since=now) · thinking이 `lastEventAt`부터 `stalledMs` 지나면 stalled · gone이 `goneMs` 지나면 제거(모자·자리 반납). 열린 도구가 있으면(running 등) 시간이 지나도 그대로.
