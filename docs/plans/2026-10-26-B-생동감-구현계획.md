# B 묶음(생동감) + Codex 실험실 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사무실이 상태를 몸짓·모니터·효과로 보여 주고, 쉬는 세션은 휴게실로 가서 돌아다니고, 밤이면 어두워지며, Codex 세션이 개발실 책상에 앉고 짝지은 서버 랙이 깜빡이게 한다.

**Architecture:** 서버(`state.ts`)는 시간 규칙(쉬기 10분·퇴근 2시간)과 Codex 💭 고침, 빌드 지문만 더한다. 화면에 순수 계산 부품 **연출 감독**(`director.ts`: 상태+시각 → 자리·방향·자세·걸음·효과)을 새로 두고, `cast.ts`는 그 계획을 실행만 한다. 효과·모니터·랙·낮밤은 각자 작은 파일(`effects.ts`·`screens.ts`·`rack.ts`·`daylight.ts`)에 순수 함수 + 얇은 그리기로 나눈다.

**Tech Stack:** Node.js 26 + TypeScript(서버, `node --test`), three.js 0.186 + Vite(화면), CSS 움직임.

**Spec:** `docs/specs/2026-10-26-B-생동감-Codex-실험실-설계.md` (실행자는 설계서와 이 계획을 함께 읽는다)

## Global Constraints

- 작업 폴더 `~/developer/synthetic-office-b`(git worktree). 원래 폴더 `~/developer/synthetic-office`(설치본)는 건드리지 않는다. 브랜치는 PR마다 `main`에서 새로(PR 1만 설계·계획 커밋이 있는 `liveliness`).
- **같은 파일을 고치는 PR은 앞 PR이 병합된 뒤 시작한다.** 병합·원래 폴더 다시 설치(`npm run install:office`)는 사용자가 그때 지시할 때만.
- `~/.codex/config.toml`·`~/.codex/hooks.json`·`~/.claude/settings.json`은 건드리지 않는다. 훅은 대화 내용을 보내지 않는다(정해진 필드만).
- 화면 확인은 **격리 서버로만**: 4310이 아닌 포트, 임시 `SO_HOME`(scratchpad 안), `scripts/demo.ts`.
- 걷는 길은 **바닥 격자 방향만**(구간마다 x만 또는 y만 바뀜). 걸음은 `PACE_FPS = { work: 16, free: 8 }`, 발과 이동은 같은 시계(`cast.ts`의 clock/steps) — 속도를 따로 정하지 않는다.
- 기본값: `restMinutes` 10, `leaveMinutes` 120, `goneMinutes` 10(그대로). 옛 `idleMinutes`는 읽지 않는다.
- 그리기 속도: 숨김 0 · 일 받은 걸음(`walk`)·이벤트 링 퍼짐 16 · 자유 걸음(`stroll`)·`wave`·`type-fast`·`scroll`·`think` 8 · 그 밖 1.
- 코드 스타일: 주석·테스트 이름은 한국어, 기존 파일의 밀도·이름 짓기를 따른다. 화면 문구는 쉬운 한국어.
- PR마다: `npm test`·`npm run typecheck`·`npm run build:web` 통과 → push → PR(base `main`) → handoff `AI-Sessions/workspace/handoff.md`의 Claude→Codex(synthetic-office) 칸에 리뷰 요청 → 위키 로그 1줄.
- 서울 좌표: 위도 37.57°, 경도 126.98°, 한국 표준시(UTC+9).

## Review Focus

1. **훅 없는(등록부만 있는) 세션의 자동 퇴근**: 등록부를 2초마다 비추는 `mirror`가 👋·😴를 ✅로 되돌려 깜빡이면 안 된다 → Task 1 테스트 `등록부 idle은 자동 퇴근을 되돌리지 않음`.
2. **휴게실로 걷던 중 다시 일을 받음**: 순간이동·대각선 없이 지나온 길을 되짚어 자리로 가야 한다 → Task 4 `simplifyPath`·`retarget` 테스트, Task 6 화면 확인.
3. **다시 설치(서버 재시작) 직후**: 열린 화면은 한 번만 새로 고침하고, 끊긴 사이 바뀐 상태로 이벤트 반짝이 몰려 터지지 않아야 한다 → Task 3 `shouldReload` 표, Task 11 `rebase` 테스트.
4. **쉬는 세션이 많음(9명 이상)**: 모두 자리를 받고 같은 점에 겹치지 않으며 화면끼리 같아야 한다 → Task 5 `restAssignments` 테스트.
5. **로비가 붐빔(Claude 9번째 이상 + Codex 4번째 이상)**: 종류가 달라도 로비 대기 자리 번호를 이어 써서 겹치지 않는다 → Task 5 `direct` 로비 테스트.
