# 캐릭터 스프라이트 연결 설계 — v15 걷기·서기 (2026-10-26)

## 목표
3D 상자 치비를 Codex가 만든 v15 도트 캐릭터로 바꾼다. 이번 범위는 **걷기·서기**다. 앉기·타이핑 같은 업무 자세는 그림이 오면 같은 자리에 끼운다.

## 사용자와 정한 것
- 사무실은 굵은 점(px 1), 사람은 가는 점. 그림을 **1.5배**로 쓴다 — 1440×900 창 기준 도트 하나 = 0.75 CSS 점(레티나 1.5 기기 점). 크기는 사무실(월드)에 묶여 창 크기를 따라 함께 커지고 작아진다.
- 세션마다 **머리×옷 조합**: 모자 번호(hat) 0~5 = 정리된 6종(JP01~KR03)의 머리·옷, 6·7 = 겹치지 않는 다른 조합.
- **표정은 상태로**: 일하는 중 = 집중(FOCUS), 끝남·내 차례 = 환한 미소(JOY), 승인·질문 대기·응답 없음 = 기본(BASE), 쉬는 중·토큰 기다림·퇴근 = 은은한 미소(SOFT). 뒷모습엔 표정이 없다.
- **도우미**: 매니저와 같은 머리·옷, 0.8배, 회의실 의자 옆에 서서 테이블을 본다.
- **걸음 두 가지**: 일을 받아 이동(출근해 자리로, 도우미 투입)은 1초 16장(2배), 일이 끝나 자유 이동(퇴근, 나중의 산책)은 1초 8장(그림 그대로). 어느 쪽이든 발과 이동은 같은 시계로 맞춘다(한 장마다 화면에서 가로 2·세로 1 도트).
- 걷는 길은 **바닥 격자 방향만**(x만 또는 y만 바뀌는 구간) — 비스듬한 4방향 그림과 맞춘다.
- 책상에서는 앉기 그림이 오기 전까지 **서기 그림으로 책상 쪽을 본다**. 상태는 말풍선·표정·모니터 색으로 보인다.

## 에셋
- v15 부품(머리·얼굴·옷 PNG 288장, 약 1.3MB, 칸 576×96 = 걷기 8 + 서기 1)을 `web/public/characters/v15/`에 복사한다. 원본 폴더 경로·버전·다시 만드는 법은 같은 폴더 `SOURCE.md`에 적는다.
- 부품 이름·레이어 순서·앵커는 `layout.json`·`catalog.json`에서 옮겨 TS 상수로 둔다.
- 합치는 순서: hairBack → farArm → farLeg → nearLeg → bottom → torso → nearArm → head → face → accessory. 얼굴 경로엔 머리 ID가 들어간다(`face/{hair}/{face}/{dir}.png`).

## 그리는 방식
- **두 해상도 합치기**: WebGL 캔버스는 기기 해상도로 만든다. 사무실은 저해상도 렌더 타깃(CSS 점 1 = 1칸)에 깊이와 함께 그린 뒤, 화면 전체 판으로 최근접 확대해 깔면서 깊이도 그대로 기록한다(셰이더 `gl_FragDepth`). 그 위에 사람을 기기 해상도로 그리면 책상·유리벽·칸막이와 서로 가리는 순서가 맞는다.
- **사람 판**: 발 위치에 세로로 선 판을 세우고 카메라 쪽으로만 돌린다(위로 눕히지 않음 — 뒤 가구와 엉뚱하게 겹치지 않게). 카메라 기울기만큼 세로를 늘려 그림 비율을 지킨다. 앵커 SE/NE [34, 88.5], SW/NW [29, 88.5]를 발 위치에 맞춘다. 투명은 alphaTest로.
- **텍스처**: (조합, 표정)마다 부품을 합쳐 576×384 아틀라스(행 SE/SW/NE/NW, 열 0~7 걷기·8 서기)를 캔버스로 만들어 캐시한다. 확대는 최근접, 도트 하나가 화면 점 하나보다 작아지는 축소(FHD 등)는 선형으로 해서 줄이 빠지지 않게 한다.
- **방향**: 걷는 구간의 월드 방향을 카메라로 화면에 투영해 dx·dy 부호로 SE/SW/NE/NW를 고른다. 서 있을 땐 자리마다 정한 방향(책상 +x 쪽 자리 = NW, 창 쪽 자리 = SE, 회의실 북쪽 의자 = SW, 남쪽 = NE).
- **프레임**: 걸은 거리를 쌓아 "한 장당 거리"로 나눠 프레임을 정한다 → 프레임 넘김과 이동이 같은 시계. 렌더 속도 조절(fps.ts)은 걷는 동안 20fps라 16장/초를 그릴 수 있다.

## 바뀌는 파일
- 새: `web/src/office/sprites/look.ts`(조합·표정·방향·프레임 계산 — 순수 함수), `atlas.ts`(부품 불러와 합치기), `figure.ts`(판·재질·갱신), `web/src/office/pixelPass.ts`(저해상도 사무실 + 깊이 합성).
- 바꿈: `cast.ts`(3D 캐릭터 → 판, 걸음 두 가지, 방향), `officeView.ts`(렌더 경로, px 기본 1), `layout.ts`(대기 자리 길 격자 방향으로, 자리별 바라보는 방향).
- 지움: `character.ts`(3D 치비).
- 안 건드림: `labels.ts`·`sort.ts`·`listBoard.ts`·`card.ts`·`bubbles.ts`·`pose.ts`(정확도·B 묶음과 겹침). 자세 이름(`Pose`)은 그대로 두고 지금은 모두 서기 그림에 잇는다.
